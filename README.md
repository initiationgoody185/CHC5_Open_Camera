CHC5_Open_Camera is an open machine vision camera app for Windows. It helps you connect a supported camera, view the live image, and work with vision features in one place.

This project is built for users who want a simple way to run a camera system without setting up a full development stack. It supports common machine vision sensor types and is made for use with FPGA-based camera hardware.

Use it to:

## 🔍 Troubleshooting

If the app does not start:

- Check that you extracted the full download
- Run the app as a normal desktop program
- Make sure Windows did not block the file
- Confirm that your PC meets the basic system needs

If the camera does not show video:

- Reconnect the camera
- Try a different USB port
- Check that the sensor type is correct
- Close other software that may already use the camera
- Restart the app and try again

If the image looks wrong:

- Check the selected sensor model
- Review exposure and gain settings
- Make sure the camera is in the correct mode
- Confirm that the lens and lighting are set up well
